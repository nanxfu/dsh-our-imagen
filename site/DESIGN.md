# 展示页设计说明 · The Develop Room

`site/` 是仓库的 GitHub Pages 宣传页，与产品内的「黑白灰印相室」（`docs/DESIGN.md`）同源：同一间屋子，只是把时间推到更早——天还没亮，屋里只有一盏安全灯。

## 一句话

深色暗房为母版。相纸是画面里唯一发亮的东西，界面退到暗处；成片随滚动显影，光标就是安全灯，掠过的地方才把颜色还回来。浅色主题是同一间屋子拉开窗帘，纸墨关系原样保留。

## 结构

| 区块 | 内容 | 说明 |
| :--- | :--- | :--- |
| Hero | 标题、导语、双 CTA、主相纸、曝光单、四张缩略样张 | 主相纸可点开大图；缩略图切换时重播一次显影 |
| 成片墙 | 22 张真实成片 + 模型与耗时题注 | CSS 多列瀑布流；进入视口时逐张显影；悬停/键盘聚焦触发安全灯显色 |
| 模型暗房 | 9 款模型的实测清单 + 大图 + 曝光单 + 提示词 | 速度刻度基于对数映射；支持按速度筛选、胶卷缩略、重播显影、复制提示词 |
| 两种用法 | 工作台截图（光桌上的一张印片）+ 三条要点 | 截图切换、模式切换；不用假浏览器窗口边框 |
| 原理与边界 | 四段流水线 + 三条事实 + 可插拔后端表 | 流水线只标方向，不做伪造进度 |
| 三步上手 | 三步纵向步骤条 | 安装方式分段（图形界面 / 一行命令 / 离线）与 Profile 切换 |
| 页脚 | 开源信息、作者频道二维码 | 二维码是纸贴片材质 |

## 令牌

深色是母版，浅色覆盖同名变量；两套都必须通过 `node site/build.mjs` 后的真实截图检查。

| 变量 | 深色 | 浅色 | 用途 |
| :--- | :--- | :--- | :--- |
| `--bg` | `#0a0a0b` | `#efece5` | 页面底色 |
| `--surface` | `#111113` | `#f8f5ee` | 下凹表面（代码行、提示词槽） |
| `--paper` | `#f2efe8` | `#fffdf8` | 相纸与主按钮底 |
| `--ink` | `#f3f1ec` | `#151517` | 主文字 |
| `--ink-2` | `#b3aea4` | `#4d4942` | 次级正文 |
| `--ink-3` | `#8f8a81` | `#5f5a52` | 注释、题注 |
| `--ink-4` | `#7b766d` | `#6a655c` | 可读的微标签下限（不再更浅） |
| `--hair` | `rgb(243 241 236 / 10%)` | `rgb(21 21 23 / 13%)` | 发丝分隔 |
| `--lamp` | `#dfa262` | `#8a5417` | 安全灯琥珀：唯一强调色 |

规则：

- 唯一强调色是琥珀，只用于状态点、选中刻度、步骤序号、聚焦成片的边；不让大面积铺色。
- 相纸是页面里最亮的表面（深色主题下白纸、浅色主题下亮白纸）。
- 语义色（成功 / 进行中 / 计划中）只在状态点与短标签上出现。
- 正文对比度：深色主题主文字约 18:1、次级约 8:1、注释约 5:1；浅色主题同级。微标签不浅于 `--ink-4`。

## 字体与排版

- 系统 UI 字栈（`-apple-system, "Segoe UI Variable Text", "Segoe UI", "PingFang SC", "Microsoft YaHei"`），不加载任何外链字体；数字一律 `tabular-nums`。
- 展示级标题用 `clamp()`：Hero `clamp(2.4rem, 4.9vw, 4.4rem)`，区块标题 `clamp(1.85rem, 3.2vw, 2.9rem)`，字距收紧到 `-0.03em`。
- 微标签最小 11px（检测器的功能性文字下限），12.5–13px 用于正文小节，15–16.5px 用于导语段落；行宽不超过 46–62 字符。
- 中英文案同构：`site/src/app.js` 里 `zh` / `en` 两份字典键集合必须一致，`data-t` / `data-t-aria` 引用的键两份都要有。

## 版式与响应式

- 容器 `1320px`，外边距 `clamp(20px, 4.6vw, 64px)`，区块纵向间距 `clamp(72px, 9vw, 128px)`。
- 成片墙列数：`4`（>1180）→ `3`（≤1180）→ `2`（≤860）；列高由 JS 按每张图的原生画幅预先分配（绝对定位瀑布流），不依赖浏览器多列分栏，避免分栏抖动与跨列断裂。
- `≤1080px` 收起顶栏导航；`≤980px` Hero 单列、模型暗房单列、流水线转纵向；`≤640px` 控件与字号降一档。

## 动效

全站只有一个主控隐喻：**暗房的光**。它由三件事表达，但共用同一套材料（光、显影、相纸）：

1. **Hero 轮播与背景光晕**：主相纸每 7 秒自动换一张真实成片（转场即一次显影），悬停、键盘聚焦、离开视口、页面隐藏、打开灯箱时都会暂停；缩略图下方有一条 1px 的琥珀进度线表示下一次轮换。同一张图同时作为巨大、模糊、径向羽化的背景光晕（`.hero-aura`），换图时以 1.5s 交叉淡入，于是整间屋子的光随画面一起变色。
2. **滚动驱动（JS 引擎，不依赖 `animation-timeline`）**：`app.js` 用 rAF 节流的滚动监听把进度写进 CSS 变量——Hero 用 `--p` 驱动相纸后退、文案下移淡出；背景照片用更慢的 `--p` 做视差；成片墙用墙面穿视口的进度 `--p` 驱动安全灯光扫；每个区块用 `--rule-p` 让顶部发丝线随进入视口生长；顶栏进度线由 `--scroll-progress` 驱动。这样 Safari、Firefox、旧版 Chromium 与 Electron 外壳表现一致，不需要 GSAP/ScrollTrigger 之类的依赖。
3. **显影与安全灯**：主相纸 1200ms 从模糊灰阶浮到清晰；成片墙每张进入视口显影一次（错峰 ≤320ms）；悬停/键盘聚焦某张成片时叠一层同源银盐副本，只有光标半径内保留颜色。

反馈与降级：

- 顶栏动效按钮可随时开/关，选择写入 `localStorage: imagen-site-motion`；关闭后暂停轮播、滚动进度与背景视差，显示一条可恢复的提示条。
- **默认动效全开，不读取系统 `prefers-reduced-motion`**（按产品方要求）；开关是这个页面唯一的降级出口。
- 触屏与 ≤780px：背景视差与墙面光扫关闭（避免大尺寸模糊层反复重栅格化），Hero 滚动后退、区块发丝线、轮播与显影保留。
- 轮播只在 Hero 可见且页面在前台时计时；所有自动播放都可被悬停或键盘焦点打断。

## 可访问性

- 跳转链接、全部交互元素真实 `button`/`a`、2px paper 色 `:focus-visible` 环、`Esc` 关闭灯箱、方向键前后翻、灯箱打开时背景 `inert` 并锁定滚动、关闭后焦点归还。
- 图片均有中文/英文 alt；装饰性副本 `aria-hidden`；异步状态用 `role="status"` 的 toast。
- 深浅主题都可切换并记忆（`localStorage`），也支持 `?theme=light|dark`、`?lang=en|zh` 覆盖，便于截图与外部链接。
- 页头内联一段阻塞脚本先套用主题，避免深色页面闪白。

## 构建与资源

```bash
node site/build.mjs   # 生成 site/dist（内联站点数据与版本号）
npm run site:build    # 同上，npm 脚本
```

- 页面是单文件产物：`index.html` + `styles.css` + `app.js`，数据（9 款模型、22 张成片、版本号）在构建期内联，不依赖运行时请求。
- 图片全部来自仓库既有资产，无外链、无新位图：成片为 `docs/assets/showcase/*.webp`（本插件在 Kaggle 2×T4 实拍生成后仅转 WebP），界面截图为 `docs/assets/*.png`（`tools/preview.mjs` 生成），作者频道二维码为 `docs/assets/social/douyin-lumen.webp`。
- 修改页面时请同步检查：中英文字典键一致、无外部位图/字体、`prefers-reduced-motion` 与 `(pointer: coarse)` 两条降级路径、以及深浅两套主题的截图。

## 已知边界

- 成片墙用两倍量的 `<img>`（颜色 + 银盐副本，同一 URL）换取安全灯效果；两者共享解码缓存，触屏与减退模式下副本不参与渲染。
- Firefox 不支持滚动驱动进度条，只少了顶部那条琥珀线；显影与安全灯仍可用。
- 灯箱不开放手势缩放与键盘 +/- 缩放；那是后续可选项。
- 展示页的视觉世界是产品世界的一次扩展，不反向约束 `client.js` 的应用界面。
