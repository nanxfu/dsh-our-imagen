# 展示页设计说明 · The Develop Room

`site/` 是仓库的 GitHub Pages 宣传页，与产品内的「黑白灰印相室」（`docs/DESIGN.md`）同源：同一间屋子，只是把时间推到更早——天还没亮，屋里只有一盏安全灯。

## 一句话

深色暗房为母版。相纸是画面里唯一发亮的东西，界面退到暗处；成片随滚动显影，光标就是安全灯，掠过的地方才把颜色还回来。浅色主题是同一间屋子拉开窗帘，纸墨关系原样保留。

## 结构

| 区块 | 内容 | 说明 |
| :--- | :--- | :--- |
| Hero | 标题、导语、双 CTA、主相纸、曝光单、四张缩略样张 | 主相纸可点开大图；缩略图切换时重播一次显影；页面加载有一段一次性入场时间线 |
| 成片墙 | 30 张真实成片 + 模型与耗时题注 + 显影计数条 | JS 绝对定位瀑布流；进入视口时逐张显影；顶栏下方一条粘性计数条报告显影进度；悬停/键盘聚焦触发安全灯显色 |
| 模型暗房 | 9 款模型的实测清单 + 大图 + 曝光单 + 提示词 | 速度刻度基于对数映射；滚动时安全灯光带扫过清单、逐行把耗时刻度打上去；支持按速度筛选、胶卷缩略、重播显影、复制提示词 |
| 两种用法 | 工作台截图（光桌上的一张印片）+ 三条要点 | 桌面端钉住约 2.2 屏：安全灯放大镜依次停在参数面板、模型选择、历史画廊三处，放大镜外的截图退回银盐；工作台 / 对话两种模式切换取景；窄屏退回普通图文块 |
| 原理与边界 | 四段流水线（钉屏「光路」叙事）+ 三条事实 + 可插拔后端表 | 滚动时点亮四个环节，最后一步让空白相纸显影；只标方向，不做伪造进度 |
| 三步上手 | 三步纵向步骤条 + 纵向光路 | 安装方式分段（图形界面 / 一行命令 / 离线）与 Profile 切换；阅读进度驱动左侧光路往下走，当前一步的序号与标题点亮，步骤标题在桌面端粘在视口里 |
| 页脚 | 开源信息、作者频道二维码 | 二维码是纸贴片材质 |

## 令牌

深色是母版，浅色覆盖同名变量；两套都必须通过 `node site/build.mjs` 后的真实截图检查。

| 变量 | 深色 | 浅色 | 用途 |
| :--- | :--- | :--- | :--- |
| `--bg` | `#0a0a0b` | `#efece5` | 页面底色 |
| `--surface` | `#111113` | `#f8f5ee` | 下凹表面（代码行、提示词槽） |
| `--paper` | `#f2efe8` | `#fffdf8` | 相纸与主按钮底 |
| `--ink` | `#f3f1ec` | `#151517` | 主文字 |
| `--ink-2` | `#b3aea4` | `#4d4942` | 次级正文 |
| `--ink-3` | `#8f8a81` | `#5f5a52` | 注释、题注 |
| `--ink-4` | `#8a857c` | `#6a655c` | 可读的微标签下限（不再更浅） |
| `--ink-on-paper` | `#121214` | `#151517` | 相纸上的墨色：相纸在深浅两套里都是最亮表面，所以两套都用深墨 |
| `--hair` | `rgb(243 241 236 / 10%)` | `rgb(21 21 23 / 13%)` | 发丝分隔 |
| `--lamp` | `#dfa262` | `#8a5417` | 安全灯琥珀：唯一强调色 |

规则：

- 唯一强调色是琥珀，只用于状态点、选中刻度、步骤序号、聚焦成片的边；不让大面积铺色。
- 相纸是页面里最亮的表面（深色主题下白纸、浅色主题下亮白纸）。
- 语义色（成功 / 进行中 / 计划中）只在状态点与短标签上出现。
- 正文对比度：深色主题主文字约 18:1、次级约 8:1、注释约 5:1；浅色主题同级。微标签不浅于 `--ink-4`。

## 字体与排版

- 系统 UI 字栈（`-apple-system, "Segoe UI Variable Text", "Segoe UI", "PingFang SC", "Microsoft YaHei"`），不加载任何外链字体；数字一律 `tabular-nums`。
- 展示级标题用 `clamp()`：Hero `clamp(2.4rem, 4.9vw, 4.4rem)`，区块标题 `clamp(1.85rem, 3.2vw, 2.9rem)`，字距收紧到 `-0.03em`。
- 微标签最小 11px（检测器的功能性文字下限），12.5–13px 用于正文小节，15–16.5px 用于导语段落；行宽不超过 46–62 字符。
- 中英文案同构：`site/src/js/i18n.js` 里 `zh` / `en` 两份字典键集合必须一致，`data-t` / `data-t-aria` 引用的键两份都要有。构建脚本会静态校验这两条，不一致直接失败。

## 版式与响应式

- 容器 `1320px`，外边距 `clamp(20px, 4.6vw, 64px)`，区块纵向间距 `clamp(72px, 9vw, 128px)`。
- 成片墙列数：`4`（>1180）→ `3`（≤1180）→ `2`（≤860）；列高由 JS 按每张图的原生画幅预先分配（绝对定位瀑布流），不依赖浏览器多列分栏，避免分栏抖动与跨列断裂。
- 三个粘性场景都只在 `≥981px` 且动效开启时成立：光路钉屏约 1.9 屏、光桌放大镜钉屏约 2.2 屏，各自把「标题 + 图示 + 说明」作为一幕居中的场景铺满视口；成片墙计数条与三步光路是 CSS sticky + 滚动进度，不需要 JS 钉屏。
- `≤1080px` 收起顶栏导航；`≤980px` Hero 单列、模型暗房单列、流水线转纵向、光路退回静态列表、光桌放大镜退回普通图文块、步骤标题取消粘性；`≤640px` 控件与字号降一档。

## 动效

全站只有一个主控隐喻：**暗房的光**。它由同一种材料（光、显影、相纸）表达成几个不同的场景，但每个场景只做一件事，避免把同一段入场动画复制到每个区块：

1. **Hero 轮播与背景光晕**：主相纸每 7 秒自动换一张真实成片（转场即一次显影），悬停、键盘聚焦、离开视口、页面隐藏、打开灯箱时都会暂停；缩略图下方有一条 1px 的琥珀进度线表示下一次轮换。进度线本身是一条 GSAP 时间线，暂停/恢复即暂停/恢复计时。同一张图同时作为巨大、模糊、径向羽化的背景光晕（`.hero-aura`），换图时以 1.5s 交叉淡入。
2. **页面入场时间线**：标题、导语、按钮、事实行、主相纸、曝光单、缩略图依次错峰进入；主相纸同时播放一次显影。只在首屏可见时播放一次，锚点直达或回访不重放。
3. **滚动驱动（GSAP ScrollTrigger）**：Hero 相纸后退、文案下移淡出、背景照片与光圈慢速视差、曝光单与缩略图先退场、顶栏进度条、区块顶部发丝线生长、墙面安全灯光扫，全部由 ScrollTrigger 的 scrub 时间线驱动。所有锚点、错峰与暂停都走 `gsap.matchMedia()`，窄屏/触屏自动关闭昂贵的背景视差与光扫。
4. **成片墙的显影计数条**：墙面进入视口后，一条贴在顶栏下方的粘性计数条（约 36px 高）留在视野里，细进度线随墙面滚动推进，右侧计数只统计真正被 ScrollTrigger 显影过的成片（`is-developed`），读数是进度而不是装饰。
5. **模型标尺校准**：模型清单进入视口时，一条安全灯光带自上而下扫过速度标尺，光带经过的地方把该行模型的耗时刻度从灰点「打」成实点；同一时间右侧样张完成一次显影。光带与刻度都由滚动进度驱动，回滚时光带退回，已打上的刻度保持。
6. **粘性叙事「光路」**：`#flow` 在桌面端被钉住约 1.9 屏。安全灯光点在四个节点的连接线空隙里依次移动，连接线由灰发丝染成琥珀，经过的节点亮起；最后一步让右侧的空白相纸显影成一张真实成片。窄屏与动效关闭时不钉屏，四段说明保持为可顺序阅读的静态列表。
7. **粘性叙事「光桌放大镜」**：`#workflow-body` 在桌面端被钉住约 2.2 屏，铺满一屏；整张界面截图退回银盐，一枚安全灯色的圆形放大镜按「参数面板 → 模型选择 → 历史画廊」三处依次停留并放大 1.45–1.5 倍，右侧三条说明随幕点亮，截图下方的计数显示 01/03–03/03。截图切换与放大镜移动都在同一条 scrub 时间线里，切换时有一帧「快门」过渡；对话模式复用同一时间线，只把落点换成提示词、确认卡、缩略图栏。截图选择按钮在钉屏时变成「跳到对应幕」，不另做一套控件。
8. **三步光路的阅读进度**：三步上手左侧有一条纵向光路，阅读进度驱动填充与光点下行；当前一步的序号字距拉开、标题提亮，长内容在桌面端让步骤标题粘在视口里，读者始终知道自己走到第几步。窄屏不钉屏，只保留序号与标题的点亮。
9. **FLIP 灯箱**：成片墙/主相纸/模型暗房的图片点开时，灯箱相纸从被点的相纸位置放大到屏幕中央；关闭时缩回原相纸（翻页后改用短淡出，避免飞回另一张图的位置）。翻页用 0.3s 交叉淡化。

反馈与降级：

- 顶栏动效按钮可随时开/关，选择写入 `localStorage: imagen-site-motion`；关闭后撤销所有 ScrollTrigger、暂停轮播、清掉一次性动画的 inline 样式，并显示一条可恢复的提示条。重新打开时按当前滚动位置重建时间线。
- **默认动效全开，不读取系统 `prefers-reduced-motion`**（按产品方要求）；开关是这个页面唯一的降级出口。
- 触屏与 ≤780px：背景视差与墙面光扫关闭，Hero 滚动后退、区块发丝线、轮播与显影保留。
- 窄屏或关动效时，三个粘性场景各自有静态形态：光路 = 纵向列表；光桌 = 图文块 + 可用截图选择按钮；三步 = 普通步骤条（序号与标题仍会随阅读位置点亮）。成片墙计数条与模型标尺光带直接隐藏。
- 轮播只在 Hero 可见且页面在前台时计时；所有自动播放都可被悬停、键盘焦点或灯箱打断。
- 所有「换一张成片」的地方共用一个 `developFrame()` 显影函数；界面截图走更短的交叉淡化，不混用成片材质。
- **失败兜底**：页面默认展示完整内容（四段说明、空白相纸、相纸墙、实点刻度），只有脚本成功接管后才加 `is-armed` / `is-calibrating` 等类切换成轮换/隐藏状态；脚本失败时内容仍可读。

## 可访问性

- 跳转链接、全部交互元素真实 `button`/`a`、2px paper 色 `:focus-visible` 环、`Esc` 关闭灯箱、方向键前后翻、灯箱打开时背景 `inert` 与滚动锁定（`scrollbar-gutter: stable` 防止锁定造成的横向跳动）、关闭后焦点归还。
- Hero 缩略图与模型清单用按钮组 + `aria-pressed` 表达选中态；灯箱是 `role="dialog"` + `aria-modal`，内部 Tab 循环。
- 图片均有中文/英文 alt；装饰性副本 `aria-hidden`；异步状态用 `role="status"` 的 toast。
- 深浅主题都可切换并记忆（`localStorage`），也支持 `?theme=light|dark`、`?lang=en|zh`、`?motion=on|off` 覆盖，便于截图与外部链接。
- 页头内联一段阻塞脚本先套用主题，避免深色页面闪白。

## 构建与资源

```bash
npm install            # gsap / esbuild 是 devDependencies
node site/build.mjs    # 生成 site/dist（压缩产物）
node site/build.mjs --pretty   # 本地调试：不压缩
npm run site:build     # 同 node site/build.mjs，CI 使用
```

- 页面是单文件产物：`index.html` + `styles.css` + `app.js`，数据（9 款模型、30 张成片、版本号）在构建期内联，运行时不请求任何外部服务。
- `app.js` 由 `site/src/app.js` 及其 ES 模块依赖经 esbuild 打包，GSAP / ScrollTrigger / Flip 一并内联（压缩后约 180 KB，gzip 约 72 KB），仍满足「运行时零外链」。
- 源码模块按职责拆分：`js/i18n.js` 文案、`js/dom.js` 与 `js/ui.js` 基础工具、`js/motion.js` 动效开关与 GSAP 注册、`js/hero.js` / `wall.js` / `lab.js` / `workflow.js` / `install.js` / `lightbox.js` / `flow.js` / `scrollfx.js` 各自区块、`js/main.js` 启动编排。
- 动效装置按文档顺序注册（`main.js` 里先 `initFlow()` 再 `initInstall()`）：ScrollTrigger 的钉屏留白会改变其后元素的位置，注册顺序与文档顺序不一致时，后注册但更靠前的区块会算错锚点。
- 构建脚本在写盘前校验：中英文字典键一致、HTML 的 `data-t` / `data-t-aria` 引用都存在；缺一个键即失败。
- 图片全部来自仓库既有资产，无外链、无新位图：成片为 `docs/assets/showcase/*.webp`（本插件在 Kaggle 2×T4 实拍生成后仅转 WebP），界面截图为 `docs/assets/*.png`（`tools/preview.mjs` 生成），作者频道二维码为 `docs/assets/social/douyin-lumen.webp`。
- 修改页面时请同步检查：中英文字典键（构建会拦）、真实截图（深浅两套、桌面与窄屏、动效开/关）、以及 `(pointer: coarse)` 降级路径。

## 已知边界

- 成片墙用两倍量的 `<img>`（颜色 + 银盐副本，同一 URL）换取安全灯效果；两者共享解码缓存，触屏与缓存命中时不产生额外网络请求。
- 光路钉屏只在桌面且动效开启时出现；`≤980px` 或动效关闭时是一条静态的纵向/列表说明，不强行在小屏上钉屏。
- 两个钉屏场景让桌面端页面多出约 4 屏滚动长度；这是叙事成本，不是加载成本（全部资源仍在首包内）。
- 放大镜的落点写成截图百分比坐标（`js/workflow.js` 的 `ACTS`）：换截图或改截图比例时要重新核对，否则会放大错区域。
- 灯箱翻页后关闭不再 FLIP 回原相纸，改用淡出；手势缩放与键盘 +/- 缩放仍是后续可选项。
- GSAP 让包体从零依赖的 58 KB 变成约 182 KB（gzip 约 73 KB），换来跨浏览器的 scrub、pin 与 FLIP；若回退到零依赖方案，需要重写整条滚动时间线。
- 展示页的视觉世界是产品世界的一次扩展，不反向约束 `client.js` 的应用界面。
