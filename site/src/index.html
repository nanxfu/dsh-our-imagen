    • 每周 30 小时，实际够画多少？

      Kaggle 给每位手机认证用户每周提供 30 小时免费 2×T4 额度。按主力 SDXL Lightning（1024px，实测 6.2 秒/张）计算，理论上限一周可出 17,000+ 张图。日常每天画几十张，一周只消耗 1~2 小时。

    • 忘关机怎么办？重启会丢机器吗？

      云端实例连续空闲满 30 分钟会自动关机，避免空耗额度；也能在顶栏随时手动关。本地 .imagen/session.json 会实时记下会话状态，DSH 刷新或重启后自动探活接管旧机器，不重复开机。

    • 先把局限说清楚

      1) Kaggle 账号必须先完成手机号绑定，否则会被平台静默降级为 CPU；2) 每次冷启动要等 3~10 分钟分配机器与加载权重（开机后出图才稳定在数秒）；3) 目前处于 Preview，Colab 与本地显卡后端仍在接入。

    不用配 CUDA，只要一个 Kaggle 账号和 DeepSeek Harness。

    从 0.8.2 版本开始，就算完全不装 kaggle 命令行工具，也能在插件界面里直接用浏览器完成 OAuth 登录。

    1. 01

      准备好 Kaggle 账号

      注册或登录 Kaggle，在 Account 设置里完成 手机号认证（Phone Verification） ——这是启用免费 GPU 的硬性前提。

      方式 A · 不装 CLI（推荐新手）

      先把插件装进 DSH，随后打开「GPU 状态 → 运行设置 → 高级 → Kaggle 访问方式选直连」，在浏览器点一下授权登录即可。

      方式 B · 命令行配置
      pip install kaggle && kaggle auth login
    2. 02

      把插件装进 DSH

      1. 打开 DeepSeek Harness，进入 设置 → 插件管理 → 安装插件 ；
      2. 粘贴下面的仓库地址并确认，完成后重启 DSH：
      github:nanxfu/dsh-our-imagen
      Profile：
      dsh plugin --profile desktop add github:nanxfu/dsh-our-imagen

      安装或升级后重启 DSH，左侧工具栏会出现「生图工作台」图标。

      网络受限可从 GitHub Releases 下载 zip 解压后，在 DSH 插件管理里选「本地加载（Load Bundle）」；开发者调试可直接：

      dsh plugin --profile desktop add D:\path\to\our-free-imagen
    3. 03

      点开机，等几分钟，开始画

      进入工作台点击顶部 「开机 / 唤醒云端」 。首次启动 Kaggle 约需 3~10 分钟分配机器与拉取模型权重；状态变绿（Online）后，之后每张图通常 2~10 秒直接落入本地 imagen-output/。

      去 GitHub 看完整文档 下载 Releases
