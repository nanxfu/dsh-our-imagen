# Product

## Platform

web

## Users

在 DSH Desktop 桌面端工作的个人创作者、设计师与开发者。本机没有高端显卡（或不愿配置本地复杂 CUDA / PyTorch 环境），但需要连续出图、对比挑选并沉淀到本地工作区。辅助人群：在对话中直接让 AI 画图的 DSH 会话用户。

## Product Purpose

把 Kaggle 每周免费 GPU 算力接进 DSH Desktop，作为桌面插件提供“整页独立工作台 + 对话内工具调用”。在面板中配置提示词与参数、连续出图，图片资产 100% 留存在本地工作区的 `imagen-output/` 目录。成功标准是：开机一次，连续出图，单张稳定在 6 秒左右。

## Positioning

不依赖本机显卡、不经过第三方商业图床、无需打开繁重 WebUI 的轻量级生图工作台。复用同一个云端 GPU 实例，同时支持整页独立工作台与对话内自然语言出图。

## Operating Context

- **宿主环境**：DSH Desktop 插件架构。`main` 插槽呈现整页独立工作台，侧栏与状态徽章作为辅助入口。
- **云端算力**：
  - 远端运行于 Kaggle GPU 容器（分配 2×Tesla T4，CUDA 12.x）；
  - 账号必须完成手机号绑定（未绑定会被平台静默降级为 CPU）；
  - 首次唤醒云端实例需 Kaggle 排队调度与环境初始化（约 3~10 分钟）；
  - 实例空闲满 30 分钟自动关机释放，避免浪费每周 30 小时的免费额度。
- **资产留存**：所有生成图片落盘于当前本地工作区的 `imagen-output/` 目录，URL 直连宿主本地静态文件服务，不上传任何外部图床。
- **国际化**：中英双语必须严格同构，文案键集合一致（`src/dict/zh.js` 与 `en.js`）。

## Capabilities and Constraints

- **模型预设**：支持 SDXL Lightning（4 步极速，默认）、SDXL Turbo（1 步草图）、SDXL Base（25 步精修）与 FLUX.2-klein-4B（实验）。
- **画面调优**：5 组比例预设（1:1、16:9、9:16、4:3、3:4）、5 类风格预设、4 维润色标签（光影、材质、构图、氛围）、高级参数抽屉（步数、CFG、种子、批量）。
- **提示词工坊**：支持中英文自然语言输入；提供 5 组开箱即用的启发式场景灵感卡；支持大模型多维润色。
- **工作台交互**：单轨创作面板（320px）、自适应居中画面预览、底部最近生成横向栏、全宽瀑布流作品画廊。
- **本地资产管理**：支持在画廊中按时间线归档、提示词与模型搜索、带回参数（Recall）、生成变体（Variant）、复制文件绝对路径、一键打开系统资源管理器。
- **对话助手**：支持大模型自然语言意图解析，生成参数确认卡片后再执行出图。
- **技术与架构约束**：
  1. 客户端 Bundle：单文件打包（`client.js`），CSS 文本内联注入，不依赖外部 CSS 加载器或宿主样式管线。
  2. 纯净零外部静态资产：不包含任何外部位图资产或外部字体，图标采用统一风格手写 SVG（1.6px 圆角描边），字体统一使用系统 UI 字栈。
  3. 尺寸规范：输出图片尺寸限定在 256~1536 像素之间，且宽高必须是 8 的整数倍。

## Product Principles

1. **图片是绝对主角**：界面控件退到边缘卡片中，画布与作品占据最大视觉重心。
2. **等待过程完全透明**：排队、连接与出图是明确的状态条与阶段说明，杜绝阻塞式黑盒转圈。
3. **专业能力顺手可达**：高级参数默认收拢保持轻盈，需要微调时一步展开。
4. **资产绝对本地化**：图片路径直接可见、可复制，完全杜绝第三方依赖与隐私泄露。
5. **状态先于装饰**：任何视觉效果不能削弱状态感知、任务进度与交互可用性。

## Accessibility & Inclusion

- **快捷键交互**：`Ctrl/Cmd + Enter` 立即提交生成，`Esc` 退出大图预览与抽屉。
- **焦点感知**：所有交互元素具备清晰键盘焦点环（Focus Ring）。
- **动效减退**：严格支持系统级 `prefers-reduced-motion`，减退模式下禁用一切过渡动画。
- **色彩可读性**：正文与背景保持 ≥ 4.5:1 对比度，深浅色主题均保持清晰可辨。
