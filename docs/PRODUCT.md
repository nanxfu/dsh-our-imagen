# Product

## Platform

web

## Users

在 DSH Desktop 桌面端工作的个人创作者、设计师与开发者。本机没有高端显卡（或不愿配置本地复杂 CUDA / PyTorch 环境），但需要连续出图、对比挑选并沉淀到本地工作区。辅助人群：在对话中直接让 AI 画图的 DSH 会话用户。

## Product Purpose

把 Kaggle 免费 GPU 额度与 Google Colab（Pro）算力接进 DSH Desktop，作为桌面插件提供“整页独立工作台 + 对话内工具调用”。在面板中配置提示词与参数、连续出图，图片资产 100% 留存在本地工作区的 `imagen-output/` 目录。成功标准是：开机一次，连续出图，极速档（`SDXL Lightning`）单张稳定在 6 秒左右。

## Positioning

不依赖本机显卡、不经过第三方商业图床、无需打开繁重 WebUI 的轻量级生图工作台。复用同一个云端 GPU 实例（Kaggle 或 Colab），同时支持整页独立工作台与对话内自然语言出图。

## Operating Context

- **宿主环境**：DSH Desktop 插件架构。`main` 插槽呈现整页独立工作台，侧栏与状态徽章作为辅助入口。
- **云端算力**：
  - 远端可运行于 Kaggle GPU 容器（分配 2×Tesla T4，CUDA 12.x）或 Google Colab（免费档 T4，Colab Pro 的 L4 / A100）；
  - Kaggle：账号必须完成手机号绑定（未绑定会被平台静默降级为 CPU）；首次唤醒需排队调度与环境初始化（约 3~10 分钟）；实例空闲满 30 分钟自动关机释放，避免浪费每周 30 小时的免费额度；
  - Colab：通过 Notebook 挂载与隧道直连；显存需求更高的模型（`Z-Image Turbo`、`Qwen-Image 2.1`、`FLUX.2 Klein 9B`）仅在此来源可用，分配受平台容量影响（如 A100 高内存档可能返回 503 排队）；
  - 运行设置中的算力来源与模型资产 `providers` 能力位共同决定模型可选性，不匹配时模型卡置灰并说明原因。
- **资产留存**：所有生成图片落盘于当前本地工作区的 `imagen-output/` 目录，URL 直连宿主本地静态文件服务，不上传任何外部图床。
- **国际化**：中英双语必须严格同构，文案键集合一致（`src/dict/zh.js` 与 `en.js`）。

## Capabilities and Constraints

- **模型预设**：支持 7 款现代模型——SDXL Lightning（默认；SDXL + 4 步 LoRA）、SANA-Sprint 1.6B（1.6B 线性 DiT，2 步极速）、Z-Image Turbo（6B S3-DiT，写实摄影、中英双语文字与原生局部重绘，仅 Colab）、Qwen-Image 2.1（7B DiT + Qwen3-VL，强排版、多图参考编辑与透明背景输出，非商用，仅 Colab）、FLUX.2 Klein 4B（Apache-2.0，多图参考与扩图引擎）、FLUX.2 Klein 9B（9B 蒸馏编辑模型，HF gated、非商用，仅 Colab）、Anima Turbo v1.1（2B 二次元 DiT，非商用）；名称、家族与定位以 `models/*.json` 为唯一来源。模型资产可用 `providers` 能力位声明可用算力来源：`z-image-turbo`、`qwen-image-2.1`、`flux2-klein-9b` 声明 `["colab"]`，其余 4 款 Kaggle / Colab 均可用；当前来源不可用的模型在模型卡置灰并标「仅 Colab」，生成前预检与 Host 入队双重拦截，不静默换模型。
- **画面调优**：5 组画幅比例（1:1、16:9、9:16、4:3、3:4）、分辨率档位（长边，取自预设 `sizeOptions`，短边按比例换算）、自定义宽高折叠、高级设置（步数、CFG、种子）；生成张数 1~4 提权到页脚常驻。有参考图时「画面设置」自动让位于「出图尺寸跟随参考图」，不再展示可点却无效的尺寸控件。
- **能力驱动的显隐**：排除项只在所选模型真的消费负向词、且引导强度高于可用阈值时出现；7 款默认参数下多数隐藏（CFG 为 0 的极速模型与 `FLUX.2 Klein` 家族默认不展示），隐藏时不渲染、不提交无效参数，用户抬高 CFG 后可用。参考图、局部重绘、扩图入口只在当前模型真正支持时出现。
- **提示词工坊**：支持中英文自然语言输入；提示词为空时提供 5 组开箱即用的启发式场景灵感卡；支持大模型四维润色（光影、材质、构图、氛围，可收起 / 展开）与一键转英文。
- **工作台交互**：单轨创作面板（320px）、自适应居中画面预览、底部最近生成横向栏、全宽瀑布流作品画廊。
- **本地资产管理**：支持在画廊中按时间线归档、提示词与模型搜索、带回参数（Recall）、生成变体（Variant）、复制文件绝对路径、一键打开系统资源管理器。
- **图生图与局部重绘**：可用画廊作品作参考图整图重绘，也可在参考图上涂抹蒙版只改局部区域（画笔 / 橡皮擦 / 清空 / 反选，触控与键盘可用）。图生图 / 局部重绘由支持该能力的模型执行：Kaggle 侧由 `sdxl-lightning` 兜底（SDXL 底座复用已加载权重，不额外占显存），Colab 侧也可走 `z-image-turbo` 的原生局部重绘；专用 9 通道 `sdxl-inpaint` 权重已下线。
- **模型原生参考生图**：`FLUX.2 Klein 4B`、`FLUX.2 Klein 9B`（仅 Colab）与 `Qwen-Image 2.1`（仅 Colab）支持 1~2 张参考图作为模型图像条件；三者均按模型原生的参考 / 编辑语义工作，属弱参考，构图与主体仍由提示词与种子主导，不做强一致承诺。参考图可带 RGBA 输入，远端解码时统一转 RGB（alpha 通道不参与条件）。
- **透明背景输出**：`Qwen-Image 2.1`（仅 Colab）在提示词明确要求「透明背景 / 贴纸」时返回真透明 RGBA PNG，alpha 端到端保留（远端原样编码、Host 原样落盘、浏览器按 alpha 合成）；真机实测（2026-11-20，Colab L4）透明区 alpha≤1 占 65.3%，但透明区 RGB 仍残留（偏紫），消费端必须按 alpha 合成，不能丢弃 alpha 当 RGB 使用。
- **扩图**：舞台画布按四边扩 20% / 16:9 / 9:16 / 4:3 扩张，默认走 `flux2-klein-4b` + Outpaint LoRA 的纯绿画布条件生图；远端预设列表缺少现代扩图引擎时才回退通用局部重绘。新增区域用原图边缘像素延拓填充，产物作为原图子版本归档。
- **创作流转**：底部胶卷点击自动回填该作品参数（保留原图 Seed）并保护未提交草稿；参数面板与创作助手之间的同步记录带参数摘要但不进入对话上下文；「新建对话」开启新上下文，「新建创作」只清掉绑定上一张作品的状态。
- **对话助手**：大模型自然语言意图解析，注入 7 款模型的书写规则、负向词能力与专长；支持通用澄清（问题 + 2~4 个选项）、多轮上下文（最近对话回传）、模型建议弱提示与本地兜底。生成参数确认卡摘要优先，英文提示词 / 排除项 / 张数可内联编辑，可「按此生成」或「带入参数面板」继续调参与批量抽卡。另提供 `imagen_batch`（一次规划 1~8 条独立任务，单条失败隔离、总等待有预算）与 `imagen_recipes`（只读检索透明的风格提示词模板，不做暗箱拼接）。
- **技术与架构约束**：
  1. 客户端 Bundle：单文件打包（`client.js`），CSS 文本内联注入，不依赖外部 CSS 加载器或宿主样式管线。
  2. 图像资产内联：模型选择卡的 7 张模型海报由 6 份独立 WebP 覆盖（5 张为模型专属选图；`flux2-klein-9b` 复用 Klein 4B 海报文件，`anima-turbo-v1.1` 沿用原 Anima 手办概念图、仅改名），以 112/96px WebP 在构建期转成 data URL（base64 合计 17460 字符、含 `data:` 前缀 17598 字符，仍 ≤20KB 预算），运行时零外部图片请求、离线可用；其余界面不引入外部位图资产与字体，图标采用统一风格手写 SVG（1.6px 圆角描边），字体统一使用系统 UI 字栈。
  3. 尺寸规范：输出图片尺寸限定在 256~1536 像素之间，且宽高必须是 8 的整数倍。

## Product Principles

1. **图片是绝对主角**：界面控件退到边缘卡片中，画布与作品占据最大视觉重心。
2. **等待过程完全透明**：排队、连接与出图是明确的状态条与阶段说明，杜绝阻塞式黑盒转圈。
3. **专业能力顺手可达**：高级参数默认收拢保持轻盈，需要微调时一步展开。
4. **资产绝对本地化**：图片路径直接可见、可复制，完全杜绝第三方依赖与隐私泄露。
5. **状态先于装饰**：任何视觉效果不能削弱状态感知、任务进度与交互可用性。

## Accessibility & Inclusion

- **快捷键交互**：`Ctrl/Cmd + Enter` 立即提交生成，`Esc` 退出大图预览与抽屉。
- **焦点感知**：所有交互元素具备清晰键盘焦点环（Focus Ring）。
- **动效减退**：严格支持系统级 `prefers-reduced-motion`，减退模式下禁用一切过渡动画。
- **色彩可读性**：正文与背景保持 ≥ 4.5:1 对比度，深浅色主题均保持清晰可辨。
