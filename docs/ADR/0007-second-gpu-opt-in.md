# ADR-0007：双卡为显式开关，默认单卡

- 状态：已采纳
- 日期：2026-11-08
- 相关：[MODEL-CATALOG.md](../MODEL-CATALOG.md)

## 背景

Kaggle 免费额度提供 GPU T4 ×2（`kaggle kernels push --accelerator NvidiaTeslaT4` 即为此语义），两块卡各 16GB、PCIe 互联、无 NVLink。扩散模型的跨卡张量并行收益不确定，本机也没有实测数据。

## 决策

默认单卡；`useSecondGpu` 是显式布尔配置，开启后允许 `device_map="balanced"` 或文本编码器分卡。双卡不用于"同时跑两个任务"。

## 后果

- 默认路径的显存假设简单，UI 只需显示单卡状态。
- 需要额外的显存与耗时实测，才能决定哪些模型值得开双卡。
- 双卡并发跑两个作业被明确排除，避免会话状态机变成两套、以及配额被双倍消耗。

## 备选与否决理由

- **默认双卡**：所有模型的显存假设都要重算，且可能在 PCIe 上更慢。
- **不碰第二张卡**：放弃了容纳 Qwen-Image Q8 这类模型的可能性。
