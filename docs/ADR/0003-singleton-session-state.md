# ADR-0003：会话状态全局单例，产物按 workspace 落盘

- 状态：已采纳
- 日期：2026-11-08
- 相关：[ARCHITECTURE.md](../ARCHITECTURE.md)

## 背景

GPU 会话是一个单一的远端资源，按周计费（30 小时）。若状态按 workspace 保存，两个窗口各起一个会话就是双倍扣配额，且用户很难察觉。

## 决策

会话状态（endpoint、token、kernel_id、计时）保存在插件数据目录，全局唯一；任务记录与日志同处；生成的图片与 `meta.json` 落在 `<workspace>/imagen-output/<jobId>/`。UI 顶部标注当前会话由哪个 workspace 占用，并提供接管。

## 后果

- 配额不会因为多开窗口而翻倍。
- 用户在不同 workspace 里能看到同一个在线会话，但产物各归各的项目，符合直觉。
- 需要"占用者"字段与接管动作，增加了一个小的状态维度。

## 备选与否决理由

- **全部按 workspace 隔离**：实现最简单，但会产生多个会话，直接放大计费风险。
