# DSH 独立生图工作台产品规格书 (STUDIO_SPEC)

> **定位**：深度集成于 DSH Desktop 的独立专业生图工作台（Imagen Studio）。  
> **核心构想**：**灵感助手（Prompt Co-pilot） + 焦点舞台（Focus Stage） + 胶卷流（Filmstrip Roll）**。

---

## 1. 产品理念与第一性原理 (Philosophy)

### 1.1 为什么不做侧边栏，而要做独立工作台？
- **视觉媒介需要呼吸感**：图像生成是典型的“大画幅、高视觉刺激”创作行为。缩在侧边栏或设置页的小抽屉里，用户只能看到小缩略图，根本无法审视光影、五官、手部、细节纹理。
- **走出“极端繁琐”与“极端简陋”的第三条路**：
  - *极端繁琐（WebUI / ComfyUI）*：把底层推理参数（采样器、CFG、降噪比、潜空间节点）全堆在界面上，让普通人望而生畏；
  - *极端简陋（聊天窗口出图）*：图刷在对话流里，一旦聊了几句就被顶走，无法对比、无法以图生图、无法一键调参；
  - **DSH 生图工作台的解法**：保持极简优雅的视觉动线，将专业能力藏在顺手的交互胶囊里，把算力等待变成优雅的探索过程。

### 1.2 尊重算力现实：把“等待”转化为“体验”
Kaggle 免费 GPU 存在两个物理现实：**首次启动需要排队 5~10 分钟**，**开机后单张出图约 6 秒**。
传统界面的处理是“卡住弹窗转圈”，容易让人焦虑；本工作台的设计哲学是**异步呼吸感**：
- 排队和出图放在底栏胶卷区渲染为**带呼吸动效的任务卡**；
- 主舞台和左侧灵感区永不被锁死，用户在出图时可以继续写下一个 Prompt、挑选上一批产物、对比历史细节。

## 2. 界面结构与空间布局 (Layout & Layout Specs)

工作台在 DSH 桌面端以**独立顶层视图**呈现（拥有专属导航图标），界面由 4 个主要功能区块构成：

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│ [顶栏 Top Bar] 视图切换 (工坊/画廊)  |  云端算力胶囊 (状态/配额)  |  模型快速切换器       │
├────────────────────────┬───────────────────────────────────────────────────────────────┤
│                        │                                                               │
│ 灵感与提示词助手轨      │ 焦点大图主舞台 (Focus Stage)                                   │
│ (Left Co-pilot Rail)   │ • 占据屏幕核心黄金比例，超清居中渲染                           │
│                        │ • 悬浮操作胶囊：[以图微调] [换种子抽卡] [复制路径] [收藏]       │
│ • 风格胶囊库           │                                                               │
│ • 对话式提示词输入     ├───────────────────────────────────────────────────────────────┤
│ • AI 智能扩写建议      │ 底部胶卷流 (Filmstrip Roll)                                   │
│ • 折叠式专业参数抽屉   │ • 状态卡（排队/出图进度） + 历史批次缩略图流                    │
│                        │ • 一键点击即刻将历史大图投射回主舞台                          │
└────────────────────────┴───────────────────────────────────────────────────────────────┘
```

## 3. 功能模块详细规格 (Component Specs)

### 3.1 顶栏控制区 (Top Bar)
- **视图切换 Tabs**：
  - `工坊 (Studio)`：即时创作、调参、抽卡的主工作台；
  - `画廊 (Gallery)`：本地积累的所有历史产物大图墙与资产管理。
- **云端算力胶囊 (Compute Pill)**：
  - 动态展示当前 GPU 状态：
    - `离线 (点击唤起)`
    - `正在排队 (第 2 位 / 约 4 分钟)`
    - `模型准备中 (即将就绪)`
    - `在线 (空闲 28 分钟后自动关机)`
  - 点击弹出轻量卡片，提供一键关机与凭据检查快捷操作。
- **模型预设选择器 (Preset Selector)**：
  - 快速下拉框：`SDXL Lightning (4步极速)` / `SDXL Turbo (1步草图)` / `SDXL Base (30步精修)`。切换时自动以非破坏方式同步左侧推荐步数与推荐分辨率。

---

### 3.2 左侧：灵感与控制轨 (Left Co-pilot Rail)
宽约 320px~360px，专为 Prompt 打造的创作工作室：

#### A. 风格预设胶囊 (Style Capsules)
横向滚动展示视觉标签，点击即在背后自动注入对应风格词与负向提示词：
- `📷 真实胶片 (Cinematic Film)`
- `🎨 概念原画 (Concept Art)`
- `🌆 赛博霓虹 (Cyberpunk)`
- `🖌️ 东方水墨 (Ink Wash)`
- `🧸 3D 黏土 (Cute Clay)`

#### B. 提示词工坊与 AI 建议流 (Prompt Workshop)
- **多行提示词输入框**：支持自然语言直接输入，快捷键 `Ctrl+Enter` 立即生成；
- **AI 润色胶囊（Prompt Co-pilot）**：
  - 当用户输入简短描述（如“一只赛博猫”）时，下方自动浮现 2~3 个快速增强胶囊：
    - `✨ 丰富光影与材质细节`
    - `🎬 增加电影级景深景别`
  - 用户轻点胶囊，自动在当前输入框中平滑补全专业的英文渲染咒语；
- **负向提示词折叠区**：默认收起，提供预置的「通用排除」模版（如自动剔除模糊、畸变、肢体多指）。

#### C. 参数抽屉 (Advanced Tuning Drawer)
默认处于收起态（使用预设最优值），展开后提供图形化调节：
- **画面比例选择器**：直观的比例方块图（`1:1 方形 1024²`、`16:9 横屏 1152×648`、`9:16 竖屏 648×1152`）；
- **微调项**：生成步数滑块、CFG 引导滑块、随机种子输入框（带 `🎲 随机` 开关）、批量生成张数（1~4）。

---

### 3.3 中上部：焦点大图主舞台 (Focus Stage)
工作台的核心视觉担当，用于细致鉴赏、快速决定：

- **主视口渲染**：
  - 自适应屏幕大小，保持原比例居中展示当前选中的图片；
  - 支持鼠标滚轮平滑缩放、双击恢复 100% 原始像素查看微观细节；
- **悬浮元信息栏 (Meta Overlay)**：
  - 半透明悬浮在图片顶部边缘，显示：`分辨率 1024×1024` · `耗时 6.2s` · `种子 4829104`；
- **快捷动作胶囊栏 (Action Floating Dock)**：
  悬浮于主舞台下方，提供 5 个高频决策动作：
  1. `以此图微调 (Iterate)`：将本图的 Prompt、种子、参数一键回填至左侧控制轨；
  2. `换种子抽卡 (Reroll)`：保持一切参数不变，随机生成新种子立即再画一张；
  3. `复制文件路径 (Copy Path)`：便于用户在外部代码或文档中直接引用；
  4. `在文件夹中定位 (Reveal in Explorer)`：直接打开本地 `imagen-output/` 文件夹；
  5. `⭐ 收藏 (Favorite)`：标记为星标作品，沉淀至画廊。

---

### 3.4 底部：胶卷流 (Filmstrip Roll)
高度约 130px~150px，横向流动的创作历史轨迹：

- **批次聚合（Batch Grouping）**：
  - 每次用户点击生成（无论是 1 张还是 4 张），在胶卷流最左侧（最新位置）生成一个独立的**任务批次卡组**；
- **进行态骨架卡片 (Progress Ghost Card)**：
  - 当任务仍在远端执行时，胶卷流第一张卡片显示为带微光流动（Shimmer）动画的骨架卡：
    - 排队时文字：“云端正在排队，预计 4 分钟…”
    - 推理时文字：“正在渲染中 (已耗时 5s)…”
  - 用户可随时在左侧写下一个任务，新任务自动排队并追加新卡片；
- **点击投射交互**：
  - 点击胶卷中的任意一张缩略图，主舞台以平滑的淡入淡出动画立即切换为该图片的超清大图；
  - 缩略图角标显示所用模型或星标图标。

---

### 3.5 独立视图：资产画廊 (Gallery View)
当用户从顶栏切换到「画廊」视图时，工作台切换为沉浸式资产管理库：

- **时间线瀑布流**：按“今天”、“本周”、“更早”分段展示当前工作区内所有的生成成果；
- **智能筛选条**：
  - 按收藏（只看星标）；
  - 按模型预设过滤；
  - 提示词关键词即时搜索；
- **资产维护动作**：
  - 支持多选、批量导出或一键删除废图（释放本地磁盘空间）。

## 4. 状态反馈与异常处理设计 (Feedback & Fallback)

### 4.1 冷启动与排队降噪
- **痛点**：Kaggle 排队是唯一不可规避的客观延迟。
- **设计规则**：
  - **绝不使用全局模态阻断弹窗**；
  - 所有的排队等待只在顶栏胶囊与底栏胶卷卡片上反映；
  - 当排队完成、模型开始首张出图时，在 DSH 右下角抛出轻量 Toast 提示：`“云端生图就绪，第一张图片已生成”`。

### 4.2 错误状态人话指引
当发生异常时，主舞台展示友好的插画与明确的人话卡片：
- **手机未绑定**：
  - 提示：`Kaggle 账号缺少手机验证`
  - 动作：提供按钮直接跳转 Kaggle 个人设置页。
- **显存超限 (OOM)**：
  - 提示：`当前分辨率或步数过大，显存不足`
  - 动作：提供按钮一键重置为安全推荐分辨率（1024×1024）。
- **云端超时退出**：
  - 提示：`云端实例因闲置超过 30 分钟已自动休眠，额度已节省`
  - 动作：提供按钮「重新唤醒」。

---

## 5. 文案与设计风格指引 (Tone of Voice)

- **语言基调**：现代、专业、克制、富有创作灵性。
- **动词偏好**：
  - 用「即刻生成 / 抽卡」替代「提交任务」；
  - 用「以此图微调」替代「继承上一轮参数」；
  - 用「云端休眠」替代「远程进程退出」；
  - 用「单张耗时」替代「稳态推理时延」。
